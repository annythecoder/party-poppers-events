PARTY POPPERS EVENTS WEBSITE
===========================

Files:
- index.html: website content
- styles.css: responsive black-and-gold design
- script.js: mobile navigation and footer year
- assets/birthday-decoration.webp: your supplied event photo
- assets/party-poppers-brand-art.png: generated brand artwork

Preview locally:
1. Unzip the project.
2. Open index.html in a browser.

Free deployment (no domain purchase):
1. Create/sign in to a Vercel account at https://vercel.com
2. Choose Add New -> Project -> Deploy a static site, or import this folder using Vercel CLI.
3. If using Vercel CLI: install Node.js, run `npm i -g vercel`, open Terminal in this folder, run `vercel`, follow prompts, then run `vercel --prod`.
4. Vercel will provide a free *.vercel.app URL.

Before public launch:
- Confirm permission to publish the child's photo.
- Review the business details, phone number, email, Instagram and service descriptions.
- Add more real gallery photos and testimonials when available.

The site currently uses a CSS text wordmark for crisp scaling. The generated brand artwork is included as a supporting asset.
